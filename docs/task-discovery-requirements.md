# task-discovery 요구사항

유사도 네트워크(Heritage Archive) 이후 작업. 상사 요구사항·확보 입력·제약·가용 인프라를
기록한다 — 다른(콜드스타트) 모델에 넘겨 구체화할 원천 자료다. 구체적 해법·방법론은
의도적으로 배제한다(콜드스타트가 스스로 도출하도록).

## 상사 요구사항 (원문)

2026-07-24, 구두 전달:

> 우리 팀 사람들이 쓴 근원경쟁력 기반으로, 우리 팀의 꿈이 담긴 향후 10년 로드맵

원문 그대로 기록. 위 문장이 전달받은 전부이며, 각색·보강하지 않는다. 원 표현이 더 길거나
다르면 이 블록을 그 문장으로 교체할 것.

## 확보한 입력 데이터

부서원 ~200명이 작성한 근원경쟁력 회고. **1회성 수집(분기 반복 아님).** 사람당:

| 필드 | 내용 |
|------|------|
| `name` | 사람 이름 (실명) |
| `cl_level` | career level (CL2 / CL3 / CL4) |
| `pjt` | project part (담당 프로젝트/파트) |
| `text` | PPT 원문 — 근원경쟁력 회고 본문 |

- 실데이터는 보안 제약으로 외부 반출 불가.

### CL별 자료(문서) 구성

`text`(회고 본문)의 구성이 career level에 따라 다르다.

- **CL2 / CL3**: 3단 구성이 원칙 — ① 상반기 성과·하반기 전략 ② 커리어 회고·확보 역량
  ③ 미래 업무. (원칙일 뿐, 미준수 문서도 섞여 있음)
- **CL4**: 미래 위주 서술형 템플릿.

## 제약 및 유의사항

1. **데이터에 로드맵 자체는 없다.** 회고는 상향식·개인·근미래(≈1~3년) 과제/역량이다.
   10년·시퀀싱·전략·"꿈"은 데이터에 없고, 로드맵의 *원재료*(방향·역량갭·momentum)만 있다.
   없는 것을 지어내지 말 것.
2. **"10년"은 문자 그대로가 아니라 해석 프레임이다.** 용도는 확정 실행계획이 아니라
   리더십 토론 촉발로 추정. 기간에 과몰입 금지.
3. **실데이터 접근 불가(보안).** 눈으로 튜닝하지 못하는 상태에서 설계해야 한다. 또한
   CL2/3 3단 구성은 "원칙"일 뿐 미준수·무내용("열심히 하겠습니다") 문서가 섞이므로,
   추출이 sparse·노이즈를 견뎌야 한다.
4. **규모·비용.** ~200명, PPT 원문이 길 수 있음(입력 길이·청킹 고려). 인당 LLM 호출의
   레이트 리밋·실패 폐기 처리 필요.

## 가용 인프라

- **Elasticsearch** — kNN 벡터 검색 + BM25 키워드 + nori 한국어 형태소 분석.
- **임베딩 모델** — 내부망 BGE-M3 (OpenAI-compatible 엔드포인트).
- **텍스트 생성 LLM** — 내부망 LLM 서버 (OpenAI-compatible, 예: Ollama). 모델 후보 미확정.

## 구체화 시 요청

- 밑바닥부터 새로 설계하기 전에, 이미 알려진 OSS·정립된 방법론이 있으면 먼저 조사해
  활용/제안할 것.
