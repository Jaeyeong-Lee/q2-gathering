# 미래 과제의 성운 — 별도 발표 시연

`future-nebula.html`을 브라우저로 연다. 네트워크 없이 작동하는 단일 HTML이며 기존 사람 지도 파일은 변경하지 않았다.

사람 → 과제로 펼치기 → PJT별 성운 → 단기·장기 → 보유·필요 역량의 다섯 장면이다. 하단 버튼, 좌우 화살표, 자동 발표(10초 간격)를 사용한다. PJT를 선택하거나 별·성운 이름·역량 원을 클릭하면 근거를 확인할 수 있다.

200명의 합성 인물, 440개 과제, 24개 로컬 카테고리를 사용한다. 자동 추출·군집의 성능을 검증한 결과가 아니다. 시간은 원문 표현을 따르며, 시점 미명시는 별도 영역이다. 역량 연결도 해당 과제의 합성 원문에 직접 명시했다. 원 크기로 gap이나 준비율을 평가하지 않는다.

첫 장면은 이전 합성 사람 지도의 좌표와 유사도 선을 재사용했다. 새로 작성한 미래 과제의 텍스트를 다시 임베딩한 결과가 아니다.

재생성: `python3 build_nebula.py`. 빌더는 이전 합성 지도 JSON만 읽고 이 디렉터리에 출력한다. HTML과 JSON은 독립적으로 보관 가능하며, 재생성에는 빌더에 기재된 합성 seed 경로가 필요하다.

브라우저 검증: `NODE_PATH=/private/tmp/auk-atlas-browser/node_modules node check_nebula.cjs` (임시 Playwright 설치 및 로컬 Chrome 사용).
