# Handoff: 근원경쟁력 150명 유사도 네트워크 시각화

## 목표
- 150명 근원경쟁력 PPT → 텍스트 추출 → 인물 간 유사도 계산 → 정적 HTML 네트워크 그래프
- 분기회(약 200명, 오디토리움) 라이브 데모용. 목적: 재미/임팩트 (formal training 아님)
- 이번 세션 목표: **로컬 환경에서 agentic 툴(Claude Code 등)로 프로토타입 제작** — 더미 데이터로 파이프라인/UI 먼저 구축

## 확정된 요구사항

### 데이터
- PPT 구조: 1인당 여러 슬라이드 (경력/역량 등 항목별로 나뉨)
- 유사도 계산 텍스트: 슬라이드 내 전체 항목 텍스트를 하나로 합쳐서 사용
- 팀/소속 정보: PPT에 없음. **별도 엑셀 명단**에 존재
- PPT ↔ 엑셀 매칭 키: **이름 + 부서 조합** (사번 아님, 이름 단독도 아님 — 동명이인 리스크)
- 파일(PPT, 엑셀): 아직 미보유. 업로드 전 구조/코드부터 준비하는 게 우선

### 유사도 계산
- 방식: **임베딩 기반 코사인 유사도** (TF-IDF는 기각 — 의미 유사성 놓침)
- 임베딩 API: **사내망 임베딩 모델 사용** (외부 API 불가 — 개인 인사정보 포함이라 보안 이슈)
  - 사내 임베딩 제공 여부는 확인된 듯하나 구체 엔드포인트/모델명은 미확인 → 다음 세션에서 확인 필요
- 계산은 **빌드 타임 1회**만 수행 (150명 텍스트 → 150개 벡터 → 150x150 코사인 유사도 매트릭스 → JSON 저장)
- 벡터DB 불필요 (검색이 아니라 전수 사전계산이므로)

### 시각화 (최종 산출물)
- **정적 HTML**, 외부 API 런타임 호출 없음 (JSON 데이터를 파일에 내장)
- 그래프 형태: **옵시디언 그래프뷰 스타일** — 150명 전체 노드 상시 노출, 클릭 시 해당 인물 하이라이트 + 나머지 dim
  - 전체 엣지를 다 그리면 스파게티화 → 인물별 유사도 상위 N(예: top 5)만 엣지로 표시
- 노드 라벨: **실명 노출** (사내 공개 범위 문제없음)
- 노드 색상: **팀/소속별 색상 구분**
- 인물 선택 UX: **검색창 + 노드 직접 클릭** 둘 다 지원

### 데모 운영
- 당일 방식: **라이브로 사회자가 자유롭게 조작** (사전 시나리오 없음, 즉흥 대응 가능해야 함)

## 미해결 / 확인 필요
1. 사내 임베딩 모델 엔드포인트/모델명, 접근 방법 (API 키? 사내망 URL?)
2. PPT 원본 파일, 엑셀 명단 파일 미확보 — 실제 텍스트 추출 로직은 더미 데이터로 먼저 검증
3. Top-N 엣지 개수 구체값 미정 (기본 5 추천, 조정 여지 있음)
4. 클릭 시 사이드 패널에 표시할 정보 항목 미정 (예: 유사 근거 텍스트, 유사도 점수, 소속 등)
5. 오디토리움 스크린 해상도/비율 — HTML 레이아웃 대응 필요할 수 있음

## 다음 세션에서 할 일 (프로토타입 범위)
1. 더미 데이터(가상 인물 10~20명, 임의 텍스트/팀)로 파이프라인 스캐폴딩
   - python-pptx로 텍스트 추출하는 부분은 실제 PPT 없이는 구조 가정만 가능 → 더미 텍스트로 대체
   - 임베딩은 사내 API 미확정이므로, 우선 로컬에서 돌아가는 대체 임베딩(예: sentence-transformers 로컬 모델)으로 목업 후 나중에 사내 API로 교체 가능하게 인터페이스 분리
2. 코사인 유사도 매트릭스 → JSON 스키마 설계 (nodes: {name, team, id}, edges: {source, target, weight})
3. d3.js force-directed 그래프 HTML 프로토타입 (검색창 + 클릭 하이라이트 + top-N 엣지 필터)
4. 실데이터 연동은 PPT/엑셀 확보 후 별도 단계로 진행

## Suggested skills (다음 에이전트가 참고)
- `frontend-design` — HTML 네트워크 그래프 UI 스타일링/디자인 결정 시 참고
- 별도 pptx 추출 로직은 정형 skill 없음 — `python-pptx` 라이브러리 직접 사용 (읽기 전용, 텍스트 추출만)
- 코드/구조 작업이 커지면 `to-prd`로 이 handoff를 PRD화하는 것도 고려 가능

## v2 추가 반영 (2026-07-11)

### 표현 방식 확정: 하이브리드 (전체 뷰 ↔ ego 뷰)
- **기본 화면**: 전체 네트워크 (top-5 엣지), 노드 크기 = degree(연결 수) 기반 → 허브 인물 부각
- **인물 클릭**: ego 뷰 전환 — 선택 인물 중앙 배치, 유사도 상위 ~10명 표시, **엣지 두께 + 노드 크기 = 유사도**, 나머지 노드는 dim 배경 유지
- **복귀**: 빈 공간 클릭 or ESC → 전체 뷰
- 전환은 d3 transition(~750ms)으로 부드럽게 — 맥락 유지가 핵심

### 조직(팀)별 필터
- 상단/사이드에 팀 색상 칩 목록, 토글 방식
- 칩 클릭 = 해당 팀 외 **dim 처리** (위치 유지) — 기본 동작
- 칩 더블클릭 or "이 팀만 보기" = **제거 + force 재배치** (팀 내부 구조 보기)
- 필터 상태에서 인물 클릭 시 → 필터된 범위 내 ego 뷰 (팀 내 유사 인물 탐색 데모 포인트)

### 시각 컨셉: "우와" 지향 (분기회 hype 목적)
- **다크 배경 + 네온 글로우 노드** (SVG filter: feGaussianBlur 기반)
- **빅뱅 인트로**: 로드 시 force alpha 1.0에서 시작 → 노드가 중앙에서 퍼지며 자리잡는 애니메이션
- **클릭 ripple 효과** + 유사 인물로 엣지 순차 점등
- **호버 툴팁**: 이름 + 팀 + 유사도 % 페이드인
- **검색창**: 타이핑 시 매칭 노드 실시간 pulse 하이라이트

### 배포
- GitHub Pages 급 정적 호스팅으로 충분 (150노드, 순수 클라이언트 d3.js — 성능 여유)
- **보안 주의**: 실명+역량 정보 포함 → public github.com Pages 금지. 사내 GitHub Enterprise Pages(사내망 전용) 또는 사내 웹서버로 배포
