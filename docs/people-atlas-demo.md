# 사람과 미래 과제 — 발표용 합성 데모

200명의 합성 회고, 8개 가상 PJT로 만든 오프라인 HTML이다. 기존 Heritage Archive는 수정하지 않는다.

```sh
python3 scripts/td_people_atlas_demo.py
open data/td_sample/people-atlas/index.html
```

출력은 `data/td_sample/people-atlas/` 아래의 `index.html`과 재검증 가능한 `synthetic-input.json`이다. 이 디렉터리의 데이터는 이 생성기가 만든 합성 자료다. 빌드에는 기존 numpy 의존성을 사용하고, LLM·외부 API·실제 자료는 사용하지 않는다. 완성 HTML은 다른 파일이나 네트워크 없이 단독으로 열 수 있다.

## 발표 흐름

1. **사람의 기록:** 200명을 살펴보고, 이름을 클릭해 회고와 유사한 사람을 확인한다.
2. **같은 미래:** 주제를 고르면 해당 미래 과제 작성자가 같은 위치에서 밝아진다.
3. **한 사람의 근거:** 미래 과제의 원문 인용, 로컬 분류와 공통 분류를 확인한다.
4. **우리 안의 경험:** 같은 주제의 경험을 쓴 사람에게 고리를 표시한다. 미래 과제와 경험을 모두 쓴 사람은 별과 고리가 함께 표시된다.
5. **첫 실험:** 미래 과제·경험 작성자를 확인하고 작은 검증 사례를 논의하는 제안을 보여준다.

하단 장면 버튼 또는 좌우 화살표로 이동한다. 자동 발표는 11초마다 다음 장면으로 이동하고 마지막 장면에서 멈춘다. 사람·주제 탐색은 자동 발표를 멈춘다. 이름·PJT·회고 검색, 전체 원문, 비슷한 사람, 지도 확대·이동, 전체 화면을 지원한다. 선택 장면·주제·인물은 URL 해시에 저장된다.

## 데이터가 의미하는 것

- 유사도는 합성 회고 전체에서 계산한 문자 2/3-gram TF-IDF의 코사인 점수다. 기존 코사인 이웃 함수를 사용하지만 실제 모델 임베딩과 동일한 결과라고 주장하지 않는다.
- 인당 상위 4명 연결을 합친 선으로 결정적 힘 배치를 만든다. 카테고리나 PJT 좌표 앵커는 사용하지 않는다. 상위 이웃이라는 사실이 강한 유사성을 보증하지는 않는다.
- facet과 카테고리는 합성 원문과 함께 작성한 fixture다. 모든 인용은 해당 인물의 원문에 존재한다. 실제 LLM 추출·검토 성능을 검증하는 데모가 아니다.
- 200명은 합성 제출자 수다. 모든 주제별 인원·경험 인원·교집합·PJT 확산도는 입력에서 계산한다. 미래 과제 미추출 15명도 지도에 남긴다.
- 이 데모는 실데이터 파이프라인용 범용 입력 어댑터가 아니다. 실제 입력 연결에는 PRD의 ID·버전·매핑 검토·참조 오류 처리가 필요하다.

## 검증

```sh
python3 -m unittest discover -s tests -p test_td_people_atlas_demo.py -v
```

원문 인용의 존재, ID 유일성, 축별 고유 인물 집계, 입력 텍스트에 따른 유사도, 안전한 HTML 데이터 삽입을 검사한다. 브라우저에서는 렌즈 집계·교집합·좌표 유지·원문 패널·검색·장면 이동·새로고침·오프라인 요청·모바일 가로 넘침을 확인한다.
