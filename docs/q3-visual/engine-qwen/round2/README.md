# engine-qwen round2 구도 설계

## 구도 원리

engine-qwen는 "무대와 무인" 구도를 채택합니다. 화면 아래 1/3을 무대 울(foam) 위처럼 낮은 그라운드 밴드로 사용하고, 지도는 그 위에서 부유합니다. 장면 문장은 극장 자막처럼 하단 밴드에서 자막처럼 뜨고 사라집니다. 인스펙터는 없으며, 클릭된 대상의 근거는 지도 위 인물 옆에서 직접 펼쳐집니다.

## 왜 이 구도인가

이 구도는 기존의 "지도 + 고정 격자" 구도에서 벗어나, 시각적 중심을 화면 하단의 무대 공간으로 이동시켜, 장면 전환과 시각적 흐름을 극장적 경험으로 재구성합니다. 지도는 무대 위에 부유하는 "성운"으로서의 역할을 하며, 시각적 흐름은 인물과 과제의 연결을 자연스럽게 보여줍니다.

## round1과의 근본적인 차이

round1에서는 지도가 전체 화면에 고정되어 있었고, 인스펙터 패널이 오른쪽에 위치했습니다. 하지만 round2에서는 지도가 무대 위에 부유하고, 하단 밴드에 장면 문장이 표시되며, 인스펙터 정보는 직접 클릭된 인물 옆에서 표시됩니다. 이는 "지금 보고 있는 대상"에 대한 정보를 시각적으로 강조하는 방식으로, 사용자의 주의를 자연스럽게 이끕니다.

## 한계

이 구도는 인스펙터 정보를 직접 클릭된 인물 옆에 표시하는 방식이므로, 동시에 많은 정보를 확인하기 어렵습니다. 또한 무대 공간에 대한 제약이 있어, 화면 크기에 따라 시각적 요소의 배치가 달라질 수 있습니다.
