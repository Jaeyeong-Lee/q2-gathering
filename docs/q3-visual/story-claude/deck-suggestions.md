# deck.md 문구 제안 — story-claude

`nebula/templates/deck.md`는 고치지 않았다. 필요할 때만 골라 반영한다. 모두 기존 키(`화면`·`보조`·`멘트`) 안에서 바뀌므로 형식 변경은 없다.

## 1-7 역량 — 카드 종류를 글로 알려 주기 (권장)

코드에 문구를 넣지 않는 규칙 때문에 카드의 확보/필요 구분은 기호(채운 민트 점 = 확보, 점선 분홍 원 = 필요)로만 보인다. 대강당에서는 기호만으로는 읽기 어렵다. 보조 줄이 범례를 맡으면 코드를 바꾸지 않고 해결된다.

```md
보조: ● 갖췄다고 쓴 경험 · ◌ 더 필요하다고 쓴 역량
```

## 1-2 wow2 유사도 — 번지는 순서를 멘트에 맞추기 (선택)

화면은 예시 인물의 별에서 시작해 유사도 연결을 따라 가까운 이웃부터 별이 번진다. 멘트가 그 순서를 짚어 주면 인과가 더 잘 읽힌다.

```md
멘트: 한 사람의 기록에서 시작해, 벡터가 닮은 사람부터 차례로 이어 봤습니다.
멘트: 한 발 물러서 보면, {people}명의 기록이 이런 지도가 됩니다.
```

## 1-3 wow3 추출 — 프리즘 은유 (선택)

얇은 삼각형(LLM)이 별을 지나가며 점화하고, 그 빛이 과제 별로 나뉜다. 발표자가 한 번만 은유를 말해 주면 아이콘 설명이 필요 없다.

```md
멘트: LLM을 프리즘처럼 썼습니다. 한 사람의 기록을 지나가게 해, 그 안에 적힌 미래 과제를 하나씩 나눠 읽었습니다.
```
