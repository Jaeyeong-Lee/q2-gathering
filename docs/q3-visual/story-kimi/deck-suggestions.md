# deck.md 문구 제안 (story-kimi)

검수에 필요 없는 선택 제안이다. `deck.md`는 고치지 않았다.

- `1-0` 두 줄("치열하게 고민해 쓴 기록들이, / 조금 더 오래 빛나도록.")은 맺음 `1-8`과 대칭이라 좋다. 다만 화면에 실루엣만 있으므로, 첫 줄이 뜨기 전 1–2초 무字의 실루엣만 보여주는 것도 고려할 만하다(구현은 story 쪽에서 가능).
- `1-1` 보조 "2Q · 텍스트 추출 → 임베딩 · 별 하나 = 사람 하나"는 화면의 다이아몬드 아이콘과 잘 맞는다. "→" 화살표가 화면 연출 순서와 같아 유지 추천.
- `1-7` 보조 "과제에 연결된 확보 · 필요 역량"은 story 카드 라벨(● 보유 경험 / ◯ 필요한 역량)과 용어가 살짝 다르다(확보 vs 보유). 한쪽으로 맞추면 청중 혼란이 줄 듯 — 엔진 장면 3은 "보유 경험"을 쓰므로 "보유 · 필요 역량" 제안.
