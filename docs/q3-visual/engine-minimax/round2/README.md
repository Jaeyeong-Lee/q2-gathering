# engine-minimax round2 — 「관제탑」 (Mission Control)

> 모델: minimax-m3 (codex exec + OpenRouter). round2 세션 2회(402 끊김 후 재시작), 총 ~420k 토큰.

## 구도 원리

1. **상단 시간축 레일** — 단기/중기/장기를 수평 스트립으로 상단에 고정. 발표가 시간의 어디에 있는지 항상 보인다.
2. **중앙 탑뷰 지도** — 전체 성운을 위에서 내려다보는 배치. 발표자의 조작 지점과 관객이 보는 것이 같은 평면에 있다.
3. **하단 상태줄** — 현재 선택 대상(인물/과제/성운)의 상태가 한 줄로 표시. 인스펙터 패널 대신 상태만 흐른다.

## round1 대비 근본적 차이

1. **오버레이가 아니라 레이아웃 재분할** — round1(지도 전면+떠 있는 HUD)과 달리, 화면을 시간/공간/상태의 3평면으로 재구성해 정보 계층이 구조 자체가 된다.
2. **시간이 상수가 된다** — 원문의 시간 표현(단기/중기/장기)을 장면 3에만 보여주는 게 아니라 상단에 항상 박아 둔다. "10년 로드맵" 요구에 대한 정직한 장치도 겸함.
3. **선택의 가시성** — 발표자가 클릭한 대상이 하단 상태줄에 실시간 표기되어, 300명이 "지금 뭘 보고 있는지"를 공유한다.

## 한계

- 탑뷰는 성좌 간 위계(가까운 사람들이 모이는 구조)의 원근감을 잃는다
- 시간축 레일과 장면 진행이 1:1이 아닌 구간(성좌/AX 렌즈)에서는 레일이 장식처럼 보일 수 있음
- 소형 화면(모바일)은 범위 밖 — 발표는 데스크탑 전제
