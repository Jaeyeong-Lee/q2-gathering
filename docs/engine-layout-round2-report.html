INSIGHTS · 방법론 인사이트

에이전트 × 모델 조합의 교훈

완성도는 루프 안정성이 좌우한다

같은 qwen이 codex exec에서는 3번 연속 탐색 중 스스로 Stop했지만, Claude Code에서는 끝까지 갔다. CC의 루프가 약한 모델을 끌고 간다. 반대로 codex exec는 강한 모델을 안정적으로 굴리되 402(크레딧) 끊김에 취약 — 재시작 컨텍스트(상태 요약+남은 것만)로 마무리 가능했다.

동시 병렬의 숨은 비용

OpenRouter는 in-flight 요청들의 예상 비용 합계로 크레딧을 잠근다. 3개 동시 대형 컨텍스트 → 잔액 충분해도 402. 동시 실행 시 잔액 ≥ 1회 예상치 × 동시수. 실험이 커질수록 "동시 3개"보다 "순차 + 저가 모델"이 실질적으로 빠르다.

가성비의 냉정한 계산

fable 사건: 1.12M 토큰 ≈ $11+, 산출물 0 — 전체 비용의 60%. 고가 모델은 탐색이 길어 실패 손실이 극대화된다.
qwen-coder-flash: 코드 품질 합격(38/38)이지만 지시 이탈·마무리 누락 반복 — 싸지만 감독 비용. 단순 조판엔 최적, 설계 재량엔 부적합.
minimax: 420k ≈ $0.6. 문맥 이어받기 좋았으나 apply_patch 미지원 → sed 우회.
kimi: 비싸지만 재작업이 적었다. 자발적 제안(용어 통일)까지.

시간 — 루프 안정성이 곧 속도

codex ~15분(1세션) · claude ~30분 · kimi ~50분(2세션) · minimax ~70분(3세션) · qwen ~90분(4세션). "빠른 모델"보다 "루프를 안 빠지는 모델"이 실제로 빠르다. qwen은 토큰당 최가지만 세션 4번에 오케스트레이터가 스크린샷까지 찍어줘야 했다.
