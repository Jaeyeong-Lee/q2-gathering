# Cosmos v2 — 단순한 화면에서 우주로

2026-09-12. 사용자가 제공한 발표 사진에서 큰 제목과 핵심 시각 자료만 남기는 명료함을 참고했다. 행사 브랜딩·기업 로고·발표 내용은 가져오지 않았다.

[발표 열기](index.html). HTML·CSS·JavaScript를 같은 폴더에 두면 오프라인으로 작동한다. 외부 폰트·라이브러리·이미지·API 요청이 없다.

## 이번 버전의 결정

- 처음부터 검은 배경. 중앙 제목 한 문장과 하나의 시각 사건을 기본으로 한다.
- 기록은 단순하게, 점화·분열·응집 순간에만 화면 전체로 확장한다.
- 긴 설명과 근거 한계는 발표자 노트로 옮긴다. 합성 시연 표시는 유지한다.
- 생성 이미지의 화려한 종이·가스 질감은 이번 버전에 넣지 않았다. 이동하는 별 자체를 중심에 둔다.
- 장면마다 모션이 끝나면 멈춘다. 자동 슬라이드 전환은 없으며 발표자가 설명 후 넘긴다.
- 파일 버전은 독립 보존한다. v1과 이전 이미지 시안은 변경하지 않았다. 이후 수정도 새 디렉터리 또는 새 파일로 만든다.

## 이야기와 와우포인트

1. **고민의 흔적:** 과거·경쟁력·미래의 기록을 되짚고 수정한다. 실제 개인 문장을 만들어 넣지 않는다.
2. 수십 개 PPT 기록이 모인다. 300은 합성 연출의 가정이다.
3. **점화:** 문서 압축 → 잠시 멈춤 → 별이 전체 화면으로 펼쳐진다.
4. 임베딩·유사도를 개념적으로 표현한다. 이때 별의 단위는 사람이다.
5. 한 사람을 확대한다. 주변이 사라지고 그 사람의 기록에 집중한다.
6. **LLM 추출 / 분열:** 한 사람의 빛이 세 개의 미래 과제로 갈라진다. 별의 단위가 바뀐다.
7. 카메라가 뒤로 빠지며 전체 기록의 과제를 펼친다.
8. **LLM 합성 / 응집:** 각 과제의 색과 이동을 유지하며 세 개의 불규칙한 성운으로 모인다.

위 네 와우포인트는 사용자의 생각을 바탕으로 한 창작 출발점이며 고정 콘티가 아니다. 추가·수정·생략 가능하다. 고민이 작위적인지, 공간 확장이 과한지 실제 시연을 보고 판단한다. 처음부터 계속 화려하기보다 평온한 장면과 큰 전환 사이에 대비를 만든다.

## 조작

- Space / →: 다음 장면. ←: 이전 장면.
- R: 현재 장면 다시 재생. P: 현재 모션 일시정지/재생.
- N: 발표자 노트. F: 브라우저가 지원하면 전체 화면.
- 마우스를 움직이면 조작부가 나타난다. 진행 바는 현재 장면을 탐색한다.
- 설정에서 속도와 움직임 줄이기를 선택한다. OS의 reduced-motion 설정을 존중한다.
- 창이 숨겨지면 일시정지한다. 현재 위치를 브라우저 로컬 저장소에 보관한다.

## 해석 경계

실제 원문·인물·내부 데이터가 없는 합성 모션 스터디다. 임베딩·LLM을 호출하지 않는다. 300명에게 각각 세 과제를 배정한 것은 연출상의 가정이며 실제 분포가 아니다. 마지막 과제군은 합성 PJT 하나의 예시다. 실제 분석은 PJT별 독립 분류와 원문 검증, 사람의 검토를 거쳐야 한다. 점의 크기·밝기·거리는 중요도·준비 수준·실행 순서를 나타내지 않는다.
