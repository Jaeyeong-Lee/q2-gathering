# 발표 시안 인덱스 — 2026-09-11

미래 과제·역량 지도를 발표로 설명하기 위한 독립 시안 모음이다. 이 폴더의 화면과 수치는 모두 설계 검토용 합성 예시다. 실제 원문·인물·내부 모델 응답·분류 결과를 담지 않는다.

## 현재 권장 시안

[Cosmos v2](pitch-cosmos-v2/index.html)는 현재 논의를 반영한 최신 모션 스터디다. 검은 배경에서 중앙 제목 한 문장과 하나의 시각 사건만 남기고, 아래 세 전환에 화면의 에너지를 집중한다.

| 전환 | 의미 | 화면에서 보이는 변화 |
|---|---|---|
| 기록 → 사람 | 작성된 기록 뒤에 사람이 있다는 관점 전환 | PPT 문서가 압축되고 별로 점화 |
| 사람 → 미래 과제 | 한 사람이 여러 미래를 적을 수 있다는 관점 전환 | 선택된 별 하나가 과제 별로 분열 |
| 미래 과제 → 과제군 | 서로 다른 기록에 흩어진 닮은 과제를 함께 읽기 | 과제 별이 이동하며 성운으로 응집 |

도입의 ‘고민의 흔적’은 실제 개인의 작성 과정이나 감정을 재현하지 않는다. 과거·근원경쟁력·미래를 되짚는 기록의 성격을 추상적인 문서와 수정 흔적으로만 표현한다.

## 사람과 모델의 역할

| 단계 | 사람이 제공·판단하는 것 | 모델 또는 코드가 돕는 것 | 화면에서 주장하지 않는 것 |
|---|---|---|---|
| 기록 | 과거 경험, 현재의 근원경쟁력, 미래에 대한 자기서술 | 입력 형식 확인 | 작성자의 실제 역량 수준·노력의 정도 |
| 사람 지도 | 어떤 질문으로 볼지, 결과를 해석할지 | 텍스트 임베딩과 유사도 계산 | 위치·거리가 사람의 우열이나 협업 적합도 |
| 미래 과제 | 원문과 추출 결과의 타당성 검토 | 근거가 있는 미래 과제 후보 추출 | 원문에 없는 계획의 생성 |
| 과제군 | 분류가 원문에 맞는지 검토하고 승인 | PJT 안에서 닮은 미래 과제 후보 합성 | 조직 전체의 확정 전략·우선순위 |
| 발표 | 어떤 질문을 회의에서 다룰지 결정 | 탐색 가능한 지도와 원문 근거 제공 | 자동 10년 로드맵·실행 순서·준비도 판정 |

실제 운영에서는 PJT별 독립 분류, 원문 근거 검증, 사람 검토가 필요하다. 시안의 별 개수, 색, 밝기, 크기, 위치, 이동 경로는 연출이다.

## Cosmos v2 사용

브라우저에서 [index.html](pitch-cosmos-v2/index.html)을 연다. 외부 라이브러리·이미지·API 호출이 없어 파일을 직접 열어도 동작한다.

- Space 또는 오른쪽 화살표: 다음 장면
- 왼쪽 화살표: 이전 장면
- R: 현재 장면 다시 재생
- P: 현재 장면 일시정지·재생
- N: 발표자 노트 열기
- F: 브라우저가 지원하면 전체 화면

각 장면의 모션은 끝나면 자동으로 멈춘다. 발표자가 설명을 끝낸 뒤 넘기는 구조다. 설정에서 속도와 움직임 줄이기를 선택할 수 있고, 운영체제의 reduced-motion 설정도 따른다.

## 다음 판단

1. 도입의 문서 흔적이 ‘치열한 고민’을 충분히 전하되 작위적이지 않은지 판단한다.
2. 점화·분열·응집 중 어디가 발표의 대표 와우포인트가 되어야 하는지 정한다.
3. 선택한 흐름을 실제 파이프라인 산출물에 연결할 때, 합성 문구·수치·과제명을 실제 검증된 값으로 교체한다.
4. 실제 인물·원문·분류 결과를 화면에 넣기 전 내부망에서 원문 근거와 검토 상태를 확인한다.

기존 후보는 삭제하거나 덮어쓰지 않는다. 새 방향은 새 파일 또는 새 폴더로만 추가한다.
