# 미래 과제·역량 지도 구현 범위

사용자 대화에서 확정한 구현 요구. 이전의 발표 데모를 실입력 파이프라인으로 확장한다.

- 입력은 파싱을 마친 사람별 텍스트, 안정적인 사람 ID, PJT, 선택적인 표시명이다. 기존 사람 유사도 네트워크를 별도 JSON으로 받아 재사용한다. PPT 파싱과 새 임베딩 생성은 범위 밖이다.
- OpenAI 호환 Chat Completions endpoint를 설정한다. JSON 응답, 단계별 지침, 구조·근거 검증, 제한된 재시도, 중간 저장·재개를 제공한다. 외부 endpoint 기본값은 없다.
- 개인별 미래 과제와 보유 경험·필요 역량을 추출한다. 과제와 직접 연결된 역량만 연결하고, 연결되지 않은 역량을 보존한다. 단기·중기·장기가 원문에 직접 명시되지 않으면 시점 미명시다. 실제 연도나 난도로 시간 구분을 만들지 않는다.
- 각 PJT에서 카테고리 초안을 만들고 정의를 비교해 정리한 뒤 개별 과제를 배정한다. 고정 카테고리 수, PJT 간 강제 통합, 과제 자동 협업 매칭은 없다. 미분류를 허용한다.
- 원문·시간·카테고리·역량 연결을 검토하고 승인·제외할 수 있다. 추출 및 로컬 taxonomy 수정 입력을 재검증하여 재처리한다. 원문 또는 결과가 바뀌면 이전 승인을 재사용하지 않는다.
- 오프라인 HTML에서 사람 네트워크, 과제 묶음, 시간 × 역량 구분의 2차원 버블을 탐색한다. X는 단기·중기·장기·시점 미명시의 범주이며, Y는 보유 경험과 확보 필요 역량의 두 영역이다. Y를 능력 점수로 해석하지 않는다.
- 버블은 PJT × 카테고리 × 시간 × 역량 종류로 집계하고 면적은 고유 작성자 수에 비례한다. 같은 사람의 여러 과제는 중복 인원으로 세지 않는다. 보유·필요 양쪽에 한 과제가 등장할 수 있다. 버블에 나오지 않는 무연결 과제와 미추출 인물도 접근 가능해야 한다.
- 각 집계에서 개별 과제, 작성자, 원문 인용, 연결 근거로 이동한다. 합성·검토 전·승인 결과를 구분하며 준비율·역량 수준·자동 10년 로드맵을 산출하지 않는다.
- 기존 Heritage Archive 및 과거 발표 HTML을 변경하지 않는다. 별도 패키지 `nebula`와 별도 출력 폴더로 제공한다.
- 합성 입력, loopback 호환 HTTP 서버, 브라우저로 전체 흐름을 검증한다. 실제 내부 LLM의 의미적 추출 성능은 내부 운영자가 원문 표본으로 확인한다.
- 내부망 에이전트가 모델 설정·실행·재개·검토·수정·최종 빌드까지 수행할 수 있는 문서를 제공한다. 코드만 브랜치에 커밋·푸시하고 민감 산출물은 커밋하지 않는다.

## 검증 경계

주 경계는 입력 JSON에서 결과 JSON과 HTML까지의 공개 파이프라인이다. 외부 의존성은 OpenAI 호환 HTTP 서버 경계에서 검증하고, 브라우저는 생성한 동일 HTML을 소비한다. 내부 헬퍼 호출 순서를 테스트 계약으로 삼지 않는다.
